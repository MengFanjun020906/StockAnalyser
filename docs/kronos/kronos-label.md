# 打标优化方案：三层复合信号筛选

---

## 一、问题：当前打标逻辑的缺陷

当前打标算法在判定买卖信号时，只比较未来上涨潜力和下跌风险的大小，**谁大算谁**。这导致一个严重问题：

| 场景 | 上涨潜力 | 下跌风险 | 当前标签 | 实际情况 |
|---|---|---|---|---|
| 干净上涨 | 0.8% | 0.0% | 强买 | 合理 |
| 剧烈震荡 | 0.8% | 0.7% | 强买 | **不合理** — 净优势仅 0.1%，高概率被止损 |
| 对称震荡 | 0.3% | 0.3% | 强卖 | **不合理** — 无方向，不应有信号 |

当上涨和下跌潜力都很大时，说明未来窗口内价格剧烈波动，方向不明确。把这样的K线标为强买/强卖，会给模型引入噪声标签。

此外，PDF 原始设计中明确提出买点需要"未来下跌风险小于给定阈值"，但当前代码实现中这个约束被简化掉了。

---

## 二、设计原则：一个好的买/卖点必须同时满足什么

从实际交易角度，一个值得标注的买点需要三个条件：

1. **赔率好** — 潜在收益显著大于潜在风险
2. **风险可控** — 最大回撤在止损容忍范围内
3. **时机对** — 处于价格拐点，而非趋势中途

当前打标只做了条件 1（且做得粗糙）和条件 3（分形过滤），**完全缺失条件 2**。

---

## 三、前置知识：阈值的两种模式

在理解三层筛选之前，需要先理清打标中"阈值"的来源。当前代码和 PDF 方案中存在两种做法：

### 硬阈值模式（当前代码的做法）

所有阈值都是人工写死的固定值：

| 参数 | 当前默认值 | 含义 |
|---|---|---|
| `threshold_percent` (T) | 0.2% | 强买/强卖的涨跌幅门槛 |
| T_weak = T × `weak_ratio` | 0.08% | 弱买/弱卖的涨跌幅门槛 |
| T_neutral = T × `neutral_ratio` | 0.02% | 中性偏多/偏空的门槛 |

**问题**：0.2% 对于 BTC 横盘期可能太宽松（到处都是信号），对于暴涨暴跌期可能太严格（几乎没有信号），不同市场状态下效果差异大。

### 自适应阈值模式（PDF 提到的做法）

阈值从**市场实际波动水平**动态推导，而非写死：

**Step 1 — 计算平均波幅**

```
平均波幅 = 过去 N 根K线的 (high - low) / close 的均值
```

这是每根K线实际振幅的统计均值，反映市场当前的波动水平。不同时期差异很大：

| 市场状态 | 5分钟K线平均波幅（举例） |
|---|---|
| BTC 横盘期 | ~0.05% |
| BTC 正常期 | ~0.15% |
| BTC 暴涨暴跌期 | ~0.5% |

**Step 2 — 从平均波幅推导所有阈值**

PDF 中的做法：`T = avg_change × 3`（即平均波动的 3 倍才算"有意义的行情"）。以此为基准，其他阈值按比例缩放：

| 阈值 | 推导公式 | 横盘期 (波幅 0.05%) | 正常期 (波幅 0.15%) | 暴涨期 (波幅 0.5%) |
|---|---|---|---|---|
| T（强信号） | 波幅 × 3 | 0.15% | 0.45% | 1.5% |
| T_weak（弱信号） | T × 0.4 | 0.06% | 0.18% | 0.6% |
| T_neutral（中性偏向） | T × 0.1 | 0.015% | 0.045% | 0.15% |

**优势**：阈值自动适配市场状态。横盘时门槛低，不会漏掉小行情；暴涨时门槛高，不会被噪声淹没。

### 两种模式的取舍

| 维度 | 硬阈值 | 自适应 |
|---|---|---|
| 实现复杂度 | 低（一个常数） | 中（需要滚动计算波幅） |
| 跨市场状态适应性 | 差 | 好 |
| 可复现性 | 强（同样参数同样结果） | 弱（依赖回看窗口选择） |
| 适用场景 | 单一市场状态的快速实验 | 长周期跨牛熊的生产打标 |

**建议**：生产环境用自适应模式，快速实验和调试可以用硬阈值。两者可以通过配置开关切换。

## 四、方案：三层复合筛选

### 第一层：风险收益比（替代当前的"比大小"）

**改变点**：用上涨/下跌的比值替代简单的大小比较，作为信号分类的主依据。

| 条件 | 标签 |
|---|---|
| up/down ≥ 3 且 up ≥ T | 强买 |
| up/down ≥ 2 且 up ≥ T_weak | 弱买 |
| up/down > 1 | 中性偏多 |
| down/up > 1 | 中性偏空 |
| down/up ≥ 2 且 down ≥ T_weak | 弱卖 |
| down/up ≥ 3 且 down ≥ T | 强卖 |
| 两者都很小 | 中性 |

这里的 T 和 T_weak 可以是硬阈值，也可以是自适应值，两种模式下判定逻辑相同。

当 down ≈ 0 时，比值趋向无穷大，视为最理想的买入条件（无下行风险），不需要特殊处理，直接满足条件。

**解决的问题**：过滤掉"涨跌差不多"的震荡区间。上涨 0.8% / 下跌 0.7% 的场景，比值仅 1.14，远低于 2 的门槛，会被正确归入中性。

**对比当前逻辑**：

| 场景 | 上涨 | 下跌 | 比值 | 当前标签 | 新标签 |
|---|---|---|---|---|---|
| 干净上涨 | 0.8% | 0.1% | 8:1 | 强买 | 强买 ✓ |
| 高波动震荡 | 0.8% | 0.7% | 1.14:1 | 强买 | **中性偏多** ✓ |
| 小行情低风险 | 0.3% | 0.1% | 3:1 | 强买 | 强买 ✓ |
| 大行情大风险 | 1.0% | 0.8% | 1.25:1 | 强买 | **中性偏多** ✓ |

### 第二层：最大回撤硬上限（新增）

**改变点**：为买卖信号增加绝对风险约束。

```
买点额外要求：下跌风险 < 回撤上限
卖点额外要求：上涨风险 < 回撤上限
```

回撤上限的计算取决于阈值模式：

| 模式 | 回撤上限计算方式 | 举例（正常期，波幅 0.15%） |
|---|---|---|
| 自适应 | `max_adverse_multiplier` × 平均波幅 | 1.5 × 0.15% = **0.225%** |
| 硬阈值 | `max_adverse_multiplier` × (T / 3) | 1.5 × (0.2% / 3) = **0.1%** |

注意硬阈值模式下，由于 T ≈ 3 × 平均波幅，需要先除以 3 还原到波幅级别，再乘以倍数。否则直接用 T 会导致上限过于宽松（1.5 × 0.2% = 0.3%，相当于 2 倍波幅，几乎不起过滤作用）。

**为什么上限基于平均波幅而非阈值 T**：

- T 定义的是"什么算有意义的行情"，通常是 3 倍波幅的量级
- 回撤上限约束的是"最大可接受的逆向波动"，应该和单根K线的正常波幅在同一量级
- 如果用 T 做上限，相当于允许 3 倍波幅的回撤，实盘中大概率已经被止损打掉了

**解决的问题**：即使风险收益比很好（比如 up=3%, down=1%, 比值 3:1），对于 5 分钟级别交易来说，1% 的绝对回撤已经很大，大概率触发止损。硬上限防止在极端波动时期标出"理论上合理但实盘不可操作"的信号。

**不满足时的处理**：不直接丢弃，而是降级——强买降为弱买，弱买降为中性偏多。

### 第三层：分形过滤（保持不变）

前两层解决了"值不值得做"和"做不做得了"，但还没回答"什么时候入场"。一个涨幅好、风险低的区间可能跨度很长，区间内任意一根K线都满足前两层条件，但显然不是每根都适合入场。分形过滤的作用就是在满足条件的区间内，找到**最佳入场时机——价格拐点**。

#### 什么是分形（Fractal）

分形是一个局部极值判断：如果当前K线的价格是前后一段范围内的最低（或最高），就认为它是一个"拐点"。

具体做法：以当前K线为中心，向前看 `fractal_window` 根K线，向后看 `fractal_window` 根K线，形成一个 `2 × fractal_window + 1` 大小的窗口。

- **局部低点（fractal low）**：当前K线的最低价 ≤ 窗口内所有K线的最低价 ×（1 + 容差）
- **局部高点（fractal high）**：当前K线的最高价 ≥ 窗口内所有K线的最高价 ×（1 − 容差）

容差（`fractal_tolerance`，默认 0.1%）允许价格不必是严格的数学最低/最高，避免因微小价差错过有效拐点。

#### 举例

以 `fractal_window = 12`（5分钟K线 × 12 = 1小时）为例：

```
K线序列：  ... [前12根] [当前K线] [后12根] ...
                        ↑
              检查：当前最低价是否 ≤ 这25根K线中的最低价 × 1.001？
              是 → 局部低点（fractal low）
              否 → 不是拐点
```

如果当前K线的最低价是 100，而前后12根K线中的最低价是 100.05，因为 100 ≤ 100.05 × 1.001 = 100.15，满足条件，判定为局部低点。

#### 对信号的约束

分形过滤作为第三层，对前两层产出的信号施加入场时机约束：

| 信号 | 分形要求 | 不满足时的处理 |
|---|---|---|
| 强买 / 弱买 | 必须是局部低点 | 降级为中性偏多（有涨幅但不在底部）或中性 |
| 强卖 / 弱卖 | 必须是局部高点 | 降级为中性偏空（有跌幅但不在顶部）或中性 |
| 中性偏多 / 偏空 / 中性 | 不要求 | 保持不变 |

#### 为什么分形过滤很重要

没有分形过滤，会出现这样的问题：在一段持续上涨的行情中，每根K线的未来涨幅都很大、下跌风险都很小，前两层会把它们全部标为"强买"。但实际上：

- 上涨初期的第一根K线（底部拐点）→ 是好的买点
- 上涨中途的K线 → 已经涨了一半，追高入场不合理
- 上涨末期的K线 → 即将见顶，买入更不合理

分形过滤通过要求"必须是局部最低点"，自然地只保留了上涨初期的拐点，过滤掉了中途和末期。

#### 相关参数

| 参数 | 默认值 | 说明 | 调大的效果 | 调小的效果 |
|---|---|---|---|---|
| `fractal_window` | 12 | 前后各看多少根K线判断极值 | 要求是更大范围的极值，拐点更少但更可靠 | 判断更宽松，更多点被保留 |
| `fractal_tolerance` | 0.001 (0.1%) | 允许的价格偏差 | 更宽容，接近最低但不是严格最低也算 | 更严格，必须非常接近精确最低 |

这一层当前的实现已经合理，不需要修改。

## 五、为什么三层缺一不可

| 只用某一层 | 会漏掉什么 |
|---|---|
| 只有风险收益比 | 极端波动期（up=4%, down=1.5%）比值好但绝对风险太大，实盘止损必然被打掉 |
| 只有回撤上限 | 低波动期几乎所有点都满足上限，失去区分度，大量无方向的K线被标为买卖点 |
| 只有分形过滤 | 局部低点之后可能继续跌（下跌趋势中的反弹底），没有涨幅优势 |
| 风险收益比 + 回撤上限 | 趋势中途也可能同时满足，但入场时机不在拐点，容易追高 |
| **三层复合** | **赔率好 + 风险可控 + 时机对 → 标签质量最高** |

## 六、对标签分布的预期影响

三层复合比当前逻辑更保守，部分边界样本会从强买/强卖降级到弱买/弱卖或中性偏多/偏空。

**这是好事**，原因：

1. 7 类标签体系的 neutral_bull / neutral_bear 本来就是为这些"模棱两可"的样本设计的缓冲区
2. 被降级的样本本身就是噪声标签的高发区，放对位置比强行标为买卖点更有利于模型学习
3. 保留下来的强买/强卖信号更纯净，类内一致性更高，模型更容易学到清晰的 pattern

预期变化：
- 强买/强卖数量减少（更精准）
- 弱买/弱卖和中性偏多/偏空数量增加（接收降级样本）
- 中性数量基本不变
- 整体分布更均匀

## 七、新增参数

| 参数 | 建议默认值 | 说明 |
|---|---|---|
| `strong_rr_ratio` | 3.0 | 强买/强卖要求的最低风险收益比 |
| `weak_rr_ratio` | 2.0 | 弱买/弱卖要求的最低风险收益比 |
| `max_adverse_multiplier` | 1.5 | 最大回撤上限 = 此值 × 平均波幅 |
| `adaptive_threshold` | True/False | 是否启用自适应阈值模式 |
| `volatility_lookback` | 100 | 计算平均波幅时回看的K线数量（仅自适应模式） |
| `volatility_multiplier` | 3.0 | T = 平均波幅 × 此值（仅自适应模式） |

与现有参数的关系：
- `window_size`、`fractal_window`、`fractal_tolerance` 保持不变
- 硬阈值模式下，`threshold_percent` 仍用于定义涨跌幅的绝对门槛
- 自适应模式下，`threshold_percent` 被 `volatility_multiplier × 平均波幅` 替代
- `weak_ratio`、`neutral_ratio` 的含义不变（始终是 T 的缩放比例），但判定逻辑从"比大小"改为"比比值"

## 八、完整判定流程（改进后）

对每一根K线：

**Step 1 — 计算基础指标**
- 计算未来窗口内的上涨潜力和下跌风险（与当前相同）
- 计算近期平均波幅：过去 `volatility_lookback` 根K线的 (high − low) / close 的均值

**Step 2 — 确定阈值**
- 自适应模式：T = 平均波幅 × `volatility_multiplier`，T_weak = T × `weak_ratio`，T_neutral = T × `neutral_ratio`
- 硬阈值模式：T = `threshold_percent`（固定值），其余按比例缩放

**Step 3 — 风险收益比分类**（替代当前的"比大小"）
- 计算 ratio = up / max(down, ε)
- 按 ratio 和阈值 T / T_weak，初步分为 7 类

**Step 4 — 回撤上限过滤**（新增）
- 计算回撤上限 = `max_adverse_multiplier` × 平均波幅
- 对买点：若 down > 回撤上限 → 降级
- 对卖点：若 up > 回撤上限 → 降级

**Step 5 — 分形过滤**（与当前相同）
- 买点必须是局部低点，否则降级
- 卖点必须是局部高点，否则降级

**Step 6 — 技术面评分**（与当前相同）
- Swing 分形、斐波那契、成交量、历史极值加分

## 九、总结

> 当前打标逻辑只问"未来涨还是跌"，优化后的逻辑问的是"未来涨多少、亏多少、划不划算、操作得了吗、时机对不对"。

三层复合的核心思想：

- **第一层（风险收益比）**：值不值得做 — 赔率必须足够好
- **第二层（回撤上限）**：做不做得了 — 风险必须在止损范围内
- **第三层（分形过滤）**：时机对不对 — 必须在拐点入场
