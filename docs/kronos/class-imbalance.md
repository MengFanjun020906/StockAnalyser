# 类别不平衡问题全景分析

> 本文从"问题是什么 → 实验中怎么体现 → 有哪些解决方法 → 我们试了什么效果如何"的逻辑，完整记录本项目中类别不平衡问题的分析过程。

---

## 一、什么是类别不平衡

在分类任务中，如果某些类别的样本数量远多于其他类别，模型会倾向于"偷懒"——直接预测多数类就能拿到很高的准确率，而忽略少数类。

**根本原因**：在梯度下降的优化过程中，每个 batch 的梯度由所有样本的 loss 求和（或求平均）得到。多数类贡献了绝大部分 loss，梯度方向由多数类主导，少数类的信号被淹没。

## 三、v3.0 基线日志中的具体不平衡迹象

以下分析基于 v3.0 基线实验（无 Focal Loss、无聚焦采样、无 class weight），重点关注 Class 0（强买）和 Class 6（强卖）。

### 迹象一：强买/强卖的 Precision 显著低于多数类——信号可信度差

在模型收敛后的最佳表现（Epoch 7，Best Macro F1 = 0.3944），各类的完整 P/R/F1：

| 类别 | 验证集样本 | Precision | Recall | F1 |
|---|---|---|---|---|
| 4 (中性偏空) | 2856 | 0.58 | **0.69** | **0.63** |
| 2 (中性偏多) | 2592 | **0.64** | 0.52 | 0.57 |
| 6 (强卖) | 840 | 0.50 | 0.38 | 0.43 |
| 0 (强买) | 776 | 0.42 | 0.42 | 0.42 |
| 1 (弱买) | 128 | 0.40 | 0.50 | 0.44 |
| 5 (弱卖) | 64 | 0.17 | 0.50 | 0.26 |

具体数据对比：

- **Class 0（强买）Precision = 0.42，Class 2（中性偏多）Precision = 0.64**，差了 0.22。模型每预测一次"强买"，正确概率只有 42%；而预测"中性偏多"的正确概率是 64%。用反推算：模型在 Epoch 7 预测了 ~784 次"强买"（= 328 / 0.42），其中 **456 次是误报**，误报率 58%。
- **Class 6（强卖）Precision = 0.50，Class 4（中性偏空）Precision = 0.58**，差了 0.08。模型预测了 ~640 次"强卖"（= 320 / 0.50），其中 **320 次是误报**，误报率 50%。
- 作为对比，Class 2 的误报率只有 36%（预测 ~2088 次，752 次误报）。

**对交易的影响**：强买/强卖是实际开仓的核心信号，但它们的 Precision 显著低于中性类，说明模型无法在强信号类别上建立清晰的决策边界。

### 迹象二：强卖的 Recall 远低于多数类——大量信号被漏掉

同样在 Epoch 7：

- **Class 6（强卖）Recall = 0.38，Class 4（中性偏空）Recall = 0.69**，差了 0.31。840 个实际的强卖时刻，模型只抓到了 320 个，**漏掉了 520 个（62%）**。
- **Class 0（强买）Recall = 0.42，Class 2（中性偏多）Recall = 0.52**，差了 0.10。776 个强买时刻漏掉了 448 个（58%）。

**Precision 和 Recall 的联合问题**：Class 0/6 不是"Precision 低但 Recall 高"或反过来，而是 **P 和 R 同时低于多数类**。这意味着模型在强信号上既不准确、又不全面。

附带 Class 1/5：
- **Class 1（弱买）**：P=0.40, R=0.50, F1=0.44。Precision 偏低，但 Recall 尚可。
- **Class 5（弱卖）**：P=0.17, R=0.50, F1=0.26。Precision 极低（每预测 6 次只对 1 次），是不平衡最严重的类。

## 四、应对方法详解

以下三种方法都在试图解决同一个问题：**调整不同样本对梯度的贡献比例**，让少数类的信号不被淹没。

### 方法一：过采样 / 降采样

**思路**：不改模型和 loss，而是改变训练数据的分布，让各类别的样本数量接近均衡。

**过采样（Oversampling）**：复制少数类的样本，让它们在训练集中出现更多次。

```
原始数据：  中性×7880  强买×1420  强卖×700
过采样后：  中性×7880  强买×7880  强卖×7880（复制5.5倍/11.3倍）
```

每个 epoch 中，模型看到三个类别的样本数量接近，梯度不再被中性类独占。

**变体 — SMOTE（合成过采样）**：不是简单复制，而是在少数类样本之间做插值，生成全新的合成样本。比如样本 A 的特征是 [0.3, 0.5]，样本 B 是 [0.5, 0.7]，合成出 C = [0.4, 0.6]。

**降采样（Undersampling）**：随机丢弃多数类的样本，让它们的数量降到和少数类接近。

| | 过采样 | 降采样 |
|---|---|---|
| 训练集大小 | 增大（少数类被复制） | 缩小（多数类被丢弃） |
| 信息利用 | 保留了所有原始数据 | **丢弃了大量多数类信息** |
| 过拟合风险 | 高：模型可能记住被反复复制的少数类样本 | 低 |
| 适用场景 | 数据总量不大时 | 数据量充足、多数类冗余度高时 |

**本质**：过采样等价于让少数类样本在每个 epoch 中被"看"更多次。从梯度的角度，这和把少数类的 loss 乘以一个倍数效果近似——**因此过采样和 loss 加权在数学上是近似等价的**（差异仅在 mini-batch 的随机性上）。

### 方法二：Loss 加权（Class Weight）

**思路**：不改数据，而是在计算 loss 时，给不同类别的样本赋予不同的权重。少数类的 loss 被放大，多数类的被缩小。

标准 CrossEntropy loss 对每个样本一视同仁：

```
总 Loss = L(样本1) + L(样本2) + ... + L(样本N)
```

加权后，每个样本的 loss 乘以其类别的权重：

```
总 Loss = w_中性 × L(中性样本) + w_强买 × L(强买样本) + w_强卖 × L(强卖样本)
```

权重通常设为类别频率的倒数：

| 类别 | 占比 | 权重（倒数归一化） |
|---|---|---|
| 中性 | 78.8% | 1.0 |
| 强买 | 14.2% | 5.5 |
| 强卖 | 7.0% | 11.3 |

这样一个强卖样本产生的梯度是一个中性样本的 11.3 倍，少数类对梯度的贡献被显著放大。

| 优点 | 缺点 |
|---|---|
| 实现简单（一行代码） | 权重选择需要调参 |
| 不改变数据集大小 | 对边界模糊的样本会过度放大梯度，导致决策边界不稳定 |
| 不引入重复样本 | 权重太大时容易过拟合到少数类 |

### 方法三：Focal Loss

**思路**：前两种方法都是**按类别**统一加权——同一个类别内所有样本的权重相同。但同一个类别内，有的样本模型已经能正确分类（"简单样本"），有的模型分不清（"困难样本"）。Focal Loss 的想法是：**按每个样本的分类难度动态加权**。

**标准 CrossEntropy 的问题**：

| 模型预测的正确概率 | CE Loss | 含义 |
|---|---|---|
| 0.95（非常自信且正确） | 0.05 | 已经学会了，loss 很小 |
| 0.50（犹豫不决） | 0.69 | 还没学会，loss 中等 |
| 0.05（完全错误） | 3.00 | 严重错误，loss 很大 |

看起来合理——越错 loss 越大。但问题是：**简单样本虽然单个 loss 小，但数量多，加起来总 loss 仍然很大**，足以主导梯度方向。

**Focal Loss 怎么做**：在 CE 的基础上，乘以一个**调制因子** `(1 − p)^γ`，其中 `p` 是模型对正确类别的预测概率，`γ` 是聚焦参数（通常取 2）：

```
CE Loss    = −log(p)
Focal Loss = −(1 − p)^γ × log(p)
```

| 模型预测的正确概率 p | CE Loss | 调制因子 (1−p)² | Focal Loss | 变化 |
|---|---|---|---|---|
| 0.95（简单样本） | 0.05 | 0.0025 | **0.000125** | 压到几乎为零 |
| 0.50（中等难度） | 0.69 | 0.25 | **0.17** | 降低到 1/4 |
| 0.05（困难样本） | 3.00 | 0.90 | **2.70** | 基本不变 |

**简单样本的 loss 被压到接近零，困难样本的 loss 基本保持不变。** 模型的学习精力自动集中到困难样本上。

γ 的作用：γ=0 退化为标准 CE；γ=2 为常用默认值；γ=5 极度聚焦。

Focal Loss 也可以叠加类别权重 α，形成 `−α × (1 − p)^γ × log(p)`。α 负责"类别层面的平衡"，(1−p)^γ 负责"样本层面的聚焦"，两者解决不同粒度的问题。

### 三种方法的统一视角

三种方法本质上都在做同一件事：**调整不同样本对梯度的贡献比例**，作用范围逐渐精细化。

| 方法 | 原理 | 加权粒度 | 解决什么 | 不能解决什么 |
|---|---|---|---|---|
| 过采样/降采样 | 改变数据分布 | 类别级（粗） | 少数类曝光不足 | 类别定义本身的问题 |
| Loss 加权 | 放大少数类 loss | 类别级（粗，但更灵活） | 少数类梯度被淹没 | 类别定义本身的问题 |
| Focal Loss | 聚焦困难样本 | 样本级（细） | 简单样本占据过多学习资源 | 困难样本本身就是噪声标签时 |

## 五、本项目的实际尝试：focus_v1 实验

针对第三节中发现的 Class 0/6 表现不佳的问题，项目进行了聚焦训练实验（focus_v1），同时使用了过采样和 loss 加权。

### 实验配置

- `focus_multiplier: 4.0`（对 0/6 过采样 4 倍）
- `inverse_freq: true`（逆频率加权）
- `class_weight_method: effective`（loss 加权）

三管齐下，目标是大幅提升 Class 0/6 的表现。

### 实验结果（Epoch 22，Focus F1 峰值 = 0.2590）

| 类别 | Precision | Recall | F1 | Correct/Total |
|---|---|---|---|---|
| 0 (强买) | 0.17 | 0.62 | 0.27 | 1493/2408 |
| 1 (弱买) | 0.11 | 0.52 | 0.18 | 416/798 |
| 2 (中性偏多) | **0.00** | **0.00** | **0.00** | **0/9837** |
| 4 (中性偏空) | **0.00** | **0.00** | **0.00** | **0/9129** |
| 5 (弱卖) | 0.12 | 0.55 | 0.20 | 493/902 |
| 6 (强卖) | 0.16 | 0.56 | 0.25 | 1433/2550 |

### 与 v3.0 基线的具体对比

| 指标 | v3_0 基线 Class 0 | focus_v1 Class 0 | 变化 |
|---|---|---|---|
| Precision | 0.42 | 0.17 | **−0.25（暴跌）** |
| Recall | 0.42 | 0.62 | +0.20（提升） |
| F1 | 0.42 | 0.27 | **−0.15（恶化）** |

| 指标 | v3_0 基线 Class 6 | focus_v1 Class 6 | 变化 |
|---|---|---|---|
| Precision | 0.50 | 0.16 | **−0.34（暴跌）** |
| Recall | 0.38 | 0.56 | +0.18（提升） |
| F1 | 0.43 | 0.25 | **−0.18（恶化）** |

### 失败分析

1. **Class 0/6 的 Recall 确实提升了**（从 0.38-0.42 提到 0.56-0.62），但 **Precision 从 0.42-0.50 暴跌到 0.16-0.17**——每发出 6 个强买/强卖信号，只有 1 个是对的
2. **Class 2/4 完全坍塌（Mode Collapse）**：Recall 全程 = 0，18,966 个样本模型一个都没预测对。多数类被彻底牺牲了
3. **整体 Accuracy 从 56% 暴跌到 15%**

分析报告（`07-analysis_v3_focus_v1.md`）的诊断：三管齐下的力度过猛，模型发现"无脑猜 0 或 6，虽然 Precision 低，但能覆盖高权重样本，loss 就能降下来"。

## 六、为什么 3 分类下这些方法全部失败

在更早期的 3 分类标签体系下，三种方法也都试过，均未带来显著提升：

| 类别 | 占比 |
|---|---|
| 中性 | 78.8% |
| 强买 | 14.2% |
| 强卖 | 7.0% |

原因不在于方法本身有问题，而在于 3 分类下的瓶颈是 **"类别在特征空间中不可分"**：中性类内部包含了微涨、微跌、横盘、先涨后跌的对冲波动等完全不同的市场状态，这些样本在特征空间中和强买/强卖的边界样本高度重叠。

- 过采样：在重叠区复制更多少数类样本 → 重叠更严重
- Loss 加权：放大重叠区少数类的梯度 → 决策边界被噪声拉扯
- Focal Loss：把注意力集中在"困难样本"上 → 但困难样本恰恰是边界上那些本身就标签模糊的样本，越关注它们噪声越大

**真正有效的方案是改变标签定义**：从 3 类扩展到 7 类（强买/弱买/中性偏多/中性/中性偏空/弱卖/强卖），让边界样本有正确的归属，从根源上消除了"类别不可分"的问题。强买 Precision 从 6% 提升到 83%。

## 七、总结

### 不平衡的具体表现（v3.0 基线日志）

集中在 **Class 0（强买）和 Class 6（强卖）** 上：

1. **Precision 显著低于多数类**：Class 0 Precision 比 Class 2 低 0.22，Class 6 比 Class 4 低 0.08。信号误报率（50-58%）远高于多数类（36-42%）。
2. **Recall 同时偏低**：Class 6 Recall 比 Class 4 低 0.31，Class 0 比 Class 2 低 0.10。大量真实的强买/强卖时刻被漏掉。
3. **训练过程中退化更快**：Class 0/6 的 F1 退化幅度是 Class 2 的约 2 倍。Class 0 主要是 Recall 下降（模型越来越不敢预测强买），Class 6 是 P 和 R 同步下跌。

### 解决方法的层次

```
标签定义改进 ─── 最根本（3类→7类，消除"类别不可分"）
       ↓
过采样 / Loss 加权 ─── 类别粒度纠偏（力度必须适中）
       ↓
Focal Loss ─── 样本粒度纠偏（自动聚焦困难样本）
```

> **核心教训**：这三种方法解决的都是"模型注意力分配"问题。当根本矛盾是"标签定义导致类别不可分"时，无论怎么调整梯度分配，效果都有限。正确的做法是从数据源头出发——设计合理的标签体系。而在合理标签体系（7 分类）的基础上，如果仍存在不平衡（如 Class 0/6），则需要适度使用过采样或 Focal Loss，但力度必须控制——focus_v1 的实验证明过度纠偏（过采样 4 倍 + 逆频率 + loss 加权三管齐下）会导致模式坍塌，比不纠偏更糟糕。
