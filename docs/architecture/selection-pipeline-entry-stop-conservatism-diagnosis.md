# 条件单入场与止损保守度诊断：挂得低不低，止损窄不窄

> **一句话结论：数据支持“点位确实挂得低、止损确实偏窄”这两个事实，但不支持“因此少赚了钱”。** 121 条条件单里，入场区上沿（回测的实际成交价）中位低于决策日收盘 **4.54%**，下沿（触发线）中位低 **6.65%**；109 条可评估计划只成交 **54 条（49.5%）**，上沿低于收盘 3% 以上的计划成交率只有 **39.4%**。止损从实际成交价算中位 **3.33%（0.78 倍 ATR20）**，41 笔非零止损里 **26 笔低于 1 倍 ATR**；54 笔成交中 **40 笔（74.1%）以止损结束，持仓中位仅 1 个交易日**。
>
> 但“等回踩错过上涨”不成立：55 笔未成交标的若在决策日次日开盘买入，+5 日收益中位 **-1.08%**、+20 日 **-11.01%**；已成交标的从成交价持有 20 日，收益中位 **-9.07%**。止损后价格在 +5/+10/+20 日“收盘回到成本之上”的比例只有 **17.5% / 15.0% / 20.0%**，但“盘中触及成本”的比例是 **50.0% / 57.5% / 60.0%**；若不止损持有 20 日，止损单中位多亏 **7.74 个百分点**，止损在 **72.5%** 的情形下是对的。
>
> 因此本次诊断的判断是：**入场端是“不参与”的主因，止损端是“成交后立即被打掉”的主因；但按“造成亏损”排序，止损不是主因，单纯放宽止损在样本内会亏更多。** 真正值得先改的是入场条件——不是把挂低幅度简单收窄几个点，而是“只在深度回踩时买”这一条件需要配合趋势/结构过滤，否则提高成交率只会买到更多下跌中的股票。止损端应先修结构（禁止止损贴入场区下沿、禁止零宽区间、让止损距离随 ATR 调整），再谈放宽宽度。

## 2. 样本与口径

### 2.1 样本

- 数据源：`data/agent_reviews/entry_execution_backtest.jsonl`，共 **121 条**条件单计划；决策日范围 **2026-05-15 ~ 2026-11-11**，覆盖 **100 个代码**。
- 状态分布：`filled` **54**、`not_filled` **55**、`insufficient_start_price` **10**、`insufficient_forward_bars` **2**。
  - 后 12 条无法评估，计算成交率时用可评估分母 **109**（54/109 = 49.5%）；若按全部 121 条算为 44.6%。
- 日线：直接使用 `data/factor_eval_cache/bars_*.csv`，100 个代码全部有覆盖（单代码日线条数中位 1237 根，最少 404 根），**未新增下载**。
- 本文只做诊断，**没有修改任何策略参数、提示词、阈值或代码**。

### 2.2 关键口径（先说明，避免误读）

| 概念 | 本文口径 |
| --- | --- |
| 决策日基准价 | 决策日或之前最近一个交易日的收盘价 |
| 入场区下沿 | `entry_zone_low`，也是回测的**触发线**：当日最低价触及该价才算触发 |
| 入场区上沿 | `entry_zone_high`，也是回测的**实际成交价**：触发后按上沿成交 |
| 挂低幅度 | `(入场区价格 - 决策日收盘) / 决策日收盘`；本文同时给上沿和下沿两套 |
| 止损距离（设计口径） | `(entry_zone_low - stop_loss_price) / entry_zone_low`，反映模型写出来的计划止损 |
| 止损距离（成交口径） | `(entry_price - stop_loss_price) / entry_price`，反映真实成交后的风险 |
| ATR20 | 决策日前 21 根日线的真实波幅均值，换算成“占基准价的百分比” |
| 20 日标准差 | 决策日前 20 个日收益率的标准差，同样换算成百分比 |
| 止损后窗口 | 从 `exit_date` 的**次一交易日**起算 5/10/20 个交易日 |
| 未成交反事实 | 决策日次一交易日开盘买入，持有 5/20 个交易日收盘卖出 |

> **口径提醒（很重要）：** 回测的成交价取的是入场区**上沿**，不是下沿。也就是说，模型写“等回踩到 26.5 再买”，回测在最低价触及 26.5 后按区间上沿 27.5 成交（见 [agent_entry_execution_backtest_service.py](file:///Users/mengfanjun/Desktop/mfj/StockAnalyser/src/services/agent_entry_execution_backtest_service.py#L634-L645)）。这会让回测的入场价系统性偏高一个区间宽度（中位 **1.88%**），也会让“从成交价到止损”的距离看起来比“按下沿成交”更宽。后文的所有结论都同时标注了这两种口径。
>
> 另一个标签问题：`entry_rule=immediate` 并不表示“立即买入”，它只是 `execution_mode` 字符串里含 `open` 的推断结果（[同文件](file:///Users/mengfanjun/Desktop/mfj/StockAnalyser/src/services/agent_entry_execution_backtest_service.py#L1317-L1325)）。本样本 86 条 `immediate` 全部是 `conditional_open`，所以不能把它读成“市价单”。
>
> **修复状态（2026-11-18）：** 上述两条口径问题已在本次修复中改正——严格入场改为按入场区下沿限价成交（跳空低开取 `min(下沿, 当日 open)`），`entry_rule` 改为如实映射（`conditional_open → conditional`）。第 2、3 节的数字仍按修复前口径记录，修复后的同批次对照见第 9 节。

## 3. 问题一：入场点位——挂低多少、成交多少、错过多少

### 3.1 挂低幅度分布（121 条）

| 分位 | 入场区上沿（实际成交价） | 入场区下沿（触发线） |
| --- | ---: | ---: |
| 均值 | -4.89% | -7.06% |
| p10 | -13.19% | -15.45% |
| p25 | -8.39% | -10.69% |
| 中位数 | **-4.54%** | **-6.65%** |
| p75 | -1.66% | -3.61% |
| p90 | 0.00% | -1.08% |

- 109 条可评估计划里，**71 条（65.1%）的上沿低于决策日收盘 3% 以上**；只有 18 条（16.5%）的上沿在 -1.5% 以内。
- 入场区宽度中位 **1.88%**，p90 为 5.13%，最大 25%；**38/121 条是零宽区间**（上沿=下沿），41 条宽度不超过 1%。
- 按执行模式看：`immediate`（实为 conditional_open）上沿中位 **-5.19%**，`pullback` **-3.94%**，`unknown` **-1.81%**。也就是说，被标成“立即执行”的那一类，实际挂得最深。

**判断：** 这不是“轻微等回踩”，而是**等一次 4.5%~6.6% 的明显下跌**才买。挂低幅度是客观事实，不依赖主观解释。

### 3.2 成交率：挂得越深，成交越少

按入场区上沿的偏移分箱（仅 109 条可评估样本）：

| 上沿相对决策日收盘 | 计划数 | 成交数 | 成交率 |
| --- | ---: | ---: | ---: |
| ≤ -3% | 71 | 28 | **39.4%** |
| -3% ~ -1.5% | 10 | 8 | 80.0% |
| -1.5% ~ 0 | 16 | 13 | 81.2% |
| 0 ~ +1.5% | 2 | 2 | 100% |
| > +1.5%（高于市价的买单） | 10 | 3 | 30.0% |

- 深档（≤-3%）贡献了 71 条计划，却只成交 28 条；**这一档的未成交数（43 条）占全部 55 条未成交的 78%**。
- 浅档（-1.5%~0）成交率 81.2%，是深档的两倍多。
- 高于市价的 10 条买单（上沿 > +1.5%）成交率只有 30%，说明这类“追价单”在回测里同样很难触发。

按执行模式：

| 模式 | 可评估计划 | 成交 | 成交率 |
| --- | ---: | ---: | ---: |
| `immediate`（conditional_open） | 74 | 32 | 43.2% |
| `pullback` | 17 | 11 | 64.7% |
| `unknown` | 18 | 11 | 61.1% |

**判断：** 成交率损失主要来自“挂得深”，不是来自 `pullback` 这个标签本身。`immediate` 组挂得最深（上沿中位 -5.19%），成交率也最低。

### 3.3 成交发生在什么时候、什么价格

- 成交延迟：决策日到成交日的自然日中位 **2 天**，p90 为 5.7 天，最长 7 天；25 笔在 1 天内成交，38 笔在 3 天内，48 笔在 5 天内。
- 成交价相对**同日收盘**：中位 **+0.60%**，均值 +0.38%，p10 -4.13%，p90 +4.78%（n=54）。
- 成交价相对**同日 VWAP**：中位 **-0.83%**，均值 -0.31%，p10 -3.08%，p90 +2.40%（n=54；VWAP 用 `amount / vol * 10` 还原）。

**判断：** 成交价基本贴着触发日的市场均价，既没有明显占便宜，也没有明显吃亏。**“挂低”省下来的钱，在成交那一刻并没有体现为相对当日均价的折价**——因为触发日本身已经跌下来了。

### 3.4 因此“错过”了多少

对 55 笔未成交计划做反事实：决策日次一交易日开盘买入，持有到 +5 / +20 个交易日收盘。

| 窗口 | 样本 | 均值 | 中位数 | 胜率 |
| --- | ---: | ---: | ---: | ---: |
| +5 日 | 55 | +0.51% | **-1.08%** | 47.3% |
| +20 日 | 50 | -7.07% | **-11.01%** | 34.0% |

同时，已成交标的从**决策日收盘**起算的远期收益也不好看：

| 窗口 | 样本 | 中位数 | 胜率 |
| --- | ---: | ---: | ---: |
| +5 日 | 54 | -5.10% | 24.1% |
| +20 日 | 54 | **-11.76%** | 20.4% |

而 54 笔成交如果**从成交价买入并持有 20 日、不设止损**，收益中位是 **-9.07%**，胜率 25.9%。

**判断（这是本次诊断最重要的一条）：**
1. **“等回踩错过了上涨”不成立。** 未成交组在 +5 日基本持平（中位 -1.08%），+20 日中位 -11.01%，胜率只有 34%。没买到的并不是一批上涨的股票。
2. **“挂得低所以买得便宜”也没有转化为收益。** 成交组从成交价持有 20 日仍然中位亏 9.07%，说明这批“等到回踩”的标的整体处在下跌通道里；回踩不是错杀，而是趋势的一部分。
3. 因此入场端的核心问题不是“挂低了 4~6 个点”，而是**“深度回踩”这个条件本身在筛选下跌中的股票**。把挂低幅度收窄，会提高成交率，但如果没有趋势/结构过滤，只是买到更多正在下跌的标的。

## 4. 问题二：止损宽度——是固定百分比，还是随波动调整

### 4.1 两种口径的止损距离

54 笔成交中，49 笔有止损价（5 笔没有止损）。两种口径差异很大：

| 统计量 | 设计口径（相对入场区下沿） | 成交口径（相对实际成交价） |
| --- | ---: | ---: |
| 样本 | 49 | 49 |
| 距离为 0 的笔数 | **15** | **8** |
| 中位数 | 1.19% | **3.33%** |
| p25 | 0.00% | 1.52% |
| p75 | 4.00% | 5.45% |
| p90 | 5.62% | 7.67% |
| 非零样本中位数 | 1.93%（n=33） | — |
| 非零样本 p10 / p90 | 0.74% / 6.23% | — |
| 非零样本 min / max | 0.17% / 6.95% | — |

- **15 条计划的止损价恰好等于入场区下沿**：按模型写的计划，入场区下沿既是买入触发线、又是止损位，中间没有缓冲。
- 回测按上沿成交后，这 15 条里有一部分因为区间宽度获得了缓冲，但仍有 **8 条成交价=止损价**，全部在 1~3 个交易日内以 0% 收益平掉（禾川科技、诺思格、三环集团、海泰新光、莱特光电、振华新材、蓝特光学、泽璟制药-U）。
- 38/121 条计划是零宽区间（上沿=下沿）；另有 3 条宽度在 0~1% 之间，合计 41 条宽度 ≤1%。这直接制造了“入场即止损”的机械结构。

### 4.2 相对波动率的比例

49 笔有止损的成交，其 ATR20 中位为 **5.54%**，20 日收益率标准差中位为 **3.49%**。用非零止损（从成交价算，n=41）除以 ATR20：

| 分位 | 止损距离 / ATR20 |
| --- | ---: |
| 均值 | 1.00 |
| p10 | 0.36 |
| p25 | 0.54 |
| 中位数 | **0.78** |
| p75 | 1.56 |
| p90 | 1.92 |
| min / max | 0.02 / 2.24 |

- **26/41（63.4%）的实际止损距离低于 1 倍 ATR20**；**8/41（19.5%）低于 0.5 倍 ATR20**；20/41 低于 0.75 倍。
- 止损距离（%）与个股 ATR20（%）的相关系数只有 **-0.09**（n=41）。如果止损是随波动调整的，二者应呈明显正相关；接近 0 甚至微负，说明**没有随波动调整**。
- 从设计口径看，非零止损距离在 1% 附近聚集 6 笔、2% 附近 4 笔、5% 附近 1 笔、6% 附近 2 笔，像是主观取整的固定百分比，而不是“按 ATR 倍数”生成。

**判断：** 止损不是按波动率设定的，而是**固定/主观百分比**；中位 3.33% / 0.78 ATR，属于偏窄区间；叠加 15 条“止损贴下沿”和 8 条“成交价=止损价”，形成了明显的机械止损结构。

### 4.3 成交后的交易结果

| 指标 | 实测 |
| --- | --- |
| 成交笔数 | 54 |
| 止损/模糊止损离场 | 38 + 2 = **40（74.1%）** |
| 止盈离场 | 10（18.5%） |
| 超时离场 | 4（7.4%） |
| 持仓天数中位 | **1 个交易日**（30/54 持仓 1 天；止损单 24/40 持仓 1 天） |
| 已实现收益中位 / 均值 | **-2.54% / -1.98%** |
| 已实现胜率 | **16.7%**（p10 -7.57%，p90 +5.22%） |

**判断：** 74% 的交易以止损结束、持仓中位只有 1 天，这是“入场后立刻被打掉”的典型形态。它首先说明止损结构有问题；但**不能直接推出“止损太窄导致亏损”**，还要看止损后价格是否真的回来了（下一节）。

## 5. 问题三：止损出局后，价格有没有回到成本之上

### 5.1 总体恢复比例（40 笔止损单）

| 窗口 | 收盘回到成本之上 | 盘中最高触及成本 | 窗口内最高收盘高于成本 | 期末收益中位 |
| --- | ---: | ---: | ---: | ---: |
| +5 日 | **7/40 = 17.5%** | 20/40 = 50.0% | 14/40 = 35.0% | -6.55% |
| +10 日 | **6/40 = 15.0%** | 23/40 = 57.5% | 17/40 = 42.5% | -9.67% |
| +20 日 | **8/40 = 20.0%** | 24/40 = 60.0% | 20/40 = 50.0% | -13.42% |

- **按收盘价算，只有 15%~20% 回到成本之上**；“多数会回来”不成立。
- 按**盘中最高价**算，50%~60% 曾触及成本，说明确实有相当一部分在止损后出现过反弹。
- 但期末收益中位从 -6.55% 一路走到 -13.42%，说明**即使盘中摸到过成本，大多数标的后续仍继续下跌**。

### 5.2 按止损宽度分组

分组按**设计口径**（止损相对入场区下沿，除以 ATR20）划分，只统计 40 笔止损单：

| 分组 | 笔数 | +5 日盘中触及 / 收盘回到 | +20 日盘中触及 / 收盘回到 | +20 日收益中位 |
| --- | ---: | ---: | ---: | ---: |
| 零距离（止损=入场区下沿） | 15 | 9/15（60.0%）/ 3/15（20.0%） | 11/15（73.3%）/ 3/15（20.0%） | -10.29% |
| 窄（<1 倍 ATR） | 18 | 9/18（50.0%）/ 3/18（16.7%） | 10/18（55.6%）/ 4/18（22.2%） | -15.07% |
| 宽（≥1 倍 ATR） | 7 | 2/7（28.6%）/ 1/7（14.3%） | 3/7（42.9%）/ 1/7（14.3%） | -14.62% |

- 零距离和窄止损组的**盘中触及率**明显更高（60%、50% vs 宽止损 28.6%），说明这两组的止损更容易被正常波动扫掉。
- 但三组的**收盘恢复率**都只有 14%~22%，期末收益也都在 -10%~-15%，说明“被扫掉”之后标的并没有普遍回到成本，止损方向本身大多是对的。
- 零距离组是最干净的结构缺陷证据：15 笔里 8 笔成交价=止损价，属于“设计上就不可能扛住任何波动”。

### 5.3 止损 vs 不止损：到底谁更优

对 40 笔止损单，比较“实际止损收益”与“从成交价持有 20 日不设止损”的收益：

| 指标 | 实测 |
| --- | ---: |
| 实际止损收益中位 | -3.26% |
| 持有 20 日收益中位 | -11.69% |
| 止损相对持有少亏（中位） | **+7.74pp** |
| 止损更优的比例 | **72.5%**（29/40） |
| 持有更优的比例 | 27.5%（11/40） |

**判断：**
1. **“止损过紧扫掉正常波动”只在局部成立。** 零距离和窄止损组的盘中触及率更高（50%~60%），确实有被噪声扫出的成分；但收盘口径只有 15%~22% 回到成本，且期末收益中位 -10%~-15%，说明多数止损避免了更大的下跌。
2. **“多数止损后回到成本”不成立。** 只有盘中口径接近“多数”，收盘口径远不到。
3. **放宽止损在样本内没有收益证据。** 不止损持有 20 日中位多亏 7.74pp，止损在 72.5% 的情形下更优。
4. 因此止损端真正该改的是**结构**（零缓冲、贴下沿、不随波动），不是简单地把止损放宽几个百分点。

## 6. 哪一侧是主要问题

### 6.1 分场景判断

| 问题 | 主要矛盾 | 数据依据 |
| --- | --- | --- |
| 为什么一半计划没成交 | **入场端** | 深档（≤-3%）成交率 39.4%，浅档 81.2%；未成交组计划下沿中位 -9.85%，成交组 -4.60% |
| 为什么成交后立刻被打掉 | **止损结构** | 74.1% 止损、持仓中位 1 天；15 条止损贴下沿、8 条成交价=止损、38 条零宽区间 |
| 为什么整体不赚钱 | **不是“点位保守”** | 未成交组 +20 日中位 -11.01%，成交组从成交价持有 20 日中位 -9.07%；样本整体下跌 |
| 放宽止损能不能改善 | **不能单独放宽** | 不止损持有 20 日多亏 7.74pp，止损在 72.5% 情形下更优 |

### 6.2 结论

**如果只能选一侧作为“主要问题”，选入场端。** 理由不是“挂低了几个点”，而是：

1. 入场端同时决定了**是否参与**（成交率 49.5%，深档 39.4%）和**参与后买在什么位置**；
2. 止损端虽然制造了 74% 的止损率和 1 天的持仓中位，但样本内放宽止损会亏更多，说明它更像是“在下跌趋势中及时止损”，而不是“错误地扫掉正常波动”；
3. 真正拖累结果的是**标的本身在下跌**：成交组从成交价持有 20 日中位 -9.07%，未成交组 +20 日中位 -11.01%。在这个样本里，无论买不买、止损宽不宽，结果都偏负。

**但也要说清楚：这不是“模型太保守导致少赚”的证据。** 数据能证明的是“挂得低、止损窄、成交少、churn 高”，不能证明“如果不保守就能赚钱”。样本期整体偏下跌，保守的点位和止损在这个环境里反而是防御性的。

### 6.3 “保守到什么程度”是数据支持的

| 判断 | 是否被数据支持 | 边界 |
| --- | --- | --- |
| 挂低幅度偏大（上沿中位 -4.54%、下沿 -6.65%） | **支持** | 这是分布事实；109 条可评估计划中有 71 条（65.1%）上沿低于收盘 3% 以上 |
| 挂得低导致约一半计划不成交 | **支持** | 49.5% 成交率；深档 39.4% |
| 挂得低导致“错过上涨” | **不支持** | 未成交组 +5 中位 -1.08%、+20 中位 -11.01%，没有错过正收益 |
| 止损偏窄（中位 0.78 ATR、26/41 <1 ATR） | **支持** | 从成交价口径；设计口径更窄（非零中位 1.93%） |
| 止损不随波动调整 | **支持** | 止损距离与 ATR20 相关系数 -0.09；距离在 1%/2% 附近聚集 |
| 止损过紧扫掉正常波动 | **部分支持** | 只在盘中触及口径（50%~60%）和零/窄止损组成立；收盘口径仅 15%~22% 回到成本 |
| 放宽止损能提高收益 | **不支持** | 不止损持有 20 日多亏 7.74pp，72.5% 情形止损更优 |
| 入场/止损是当前不赚钱的主因 | **不支持** | 样本整体下跌；成交组与未成交组 20 日结果都偏负 |

## 7. 调整方向建议（只给方向，不执行）

以下建议按“证据强度”排序，任何一条都**不应直接改线上参数**；应先用现有 121 条计划做离线重放，再决定是否进入影子期。

### 7.1 第一优先：入场端做分层实验，而不是直接收窄

**不建议**把挂低幅度从 -4.5% 直接改成 -1.5%。原因是：浅档成交率虽然高（81.2%），但样本内成交标的持有 20 日中位仍亏 9.07%，单纯提高成交率可能只是买到更多下跌股。

**建议的实验设计：**

1. 把入场区上沿偏移分成三档：**-4.5%（现状）/ -2.5% / -1.5%**，其余条件不变，离线重放同一批 121 条计划。
2. 每档同时记录四个指标：**成交率、止损率、持仓天数中位、成交后 +20 日收益中位**。只有“成交率上升 + 止损率下降 + +20 日不恶化”同时出现，才算改善。
3. 叠加一个**趋势/结构过滤**再重放：例如“回踩不破 MA20”或“决策日前 20 日趋势向上”才允许挂深单。数据依据是：深档成交率只有 39.4%，且成交后仍继续下跌，说明“深回踩”本身可能是趋势走坏的信号，而不是折价机会。
4. 如果实验显示“收窄挂低 + 趋势过滤”能把 +20 日中位从 -9% 拉到 0 附近，才说明入场端是可通过参数修复的问题；如果拉不动，问题在选股/regime，不在挂低幅度。

### 7.2 第二优先：止损先修结构，再谈宽度

**优先级高于“放宽止损”的三条结构修复：**

1. **禁止止损价等于入场区下沿。** 当前 15/49 条如此，等于“触发即止损”。至少要求 `stop_loss_price < entry_zone_low`，并留出一个最小缓冲。
2. **禁止零宽入场区。** 当前 38/121 条上沿=下沿，制造了 8 条“成交价=止损价”的机械交易。可以要求 `entry_zone_high > entry_zone_low`，或对零宽区间单独标记、不参与成交统计。
3. **让止损距离与 ATR 挂钩。** 当前中位 0.78 ATR、26/41 低于 1 ATR，且与波动率相关性只有 -0.09。建议方向是 `止损距离 = max(1.2~1.5 × ATR20, 固定下限)`，把 26 条低于 1 ATR 的计划抬到与波动匹配的水平。**不建议直接放宽到 2 ATR 以上**：样本内不止损持有 20 日多亏 7.74pp，过度放宽没有证据支持。

**顺序很重要：** 先修“零缓冲/零宽区间”，再谈“1.2~1.5 ATR”。前者是结构错误，后者是参数选择；把两者混在一起改，无法判断收益变化来自哪一项。

### 7.3 度量修正：把“回测口径”和“模型保守”分开

- 回测成交价取区间上沿，比真实下限价单差一个区间宽度（中位 1.88%）。建议同时报告**上沿成交**和**下沿成交**两套结果，避免把执行口径当成模型保守。
- 单独统计 **zero-buffer**（成交价=止损价）交易，不要混在止损单里；这 8 笔是 0% 收益的机械平仓，会稀释止损单的真实亏损分布。
- 成交率建议以**可评估样本**为分母（本次 109 条，49.5%），而不是全部 121 条（44.6%），避免把数据不足的 12 条算成“未成交”。

### 7.4 验证方式：先离线重放，不动线上

1. 用同一批 121 条计划、同一份 `bars_*.csv`，按“现状 / 收窄挂低 / 修止损结构 / 两者一起”四组重放。
2. 预注册指标：成交率、止损率、持仓天数中位、成交后 +20 日收益中位、止损后 +20 日收盘恢复率。
3. 只有在“成交率上升且 +20 日收益不恶化”同时成立时，才考虑进入影子期；否则应把问题升级到选股/regime 层，而不是继续调点位。

## 8. 技术附录

### 8.1 复现方式

- 输入：`data/agent_reviews/entry_execution_backtest.jsonl`（121 条）+ `data/factor_eval_cache/bars_*.csv`（100 个代码全覆盖）。
- 读取字段：`trade_plan.entry_zone_low/high`、`trade_plan.stop_loss_price`、`trade_plan.take_profit_price`、`trade_plan.execution_mode`、`evaluation.status/entry_date/entry_price/exit_date/exit_reason/holding_days/pnl_pct`、`price_data.daily_bars`。
- ATR20：决策日前 21 根日线的 `TR = max(high-low, |high-prev_close|, |low-prev_close|)` 均值，再除以基准价换成百分比。
- 20 日标准差：决策日前 20 个日收益率的标准差，再换成百分比。
- 止损后窗口：`exit_date` 次一交易日起算；若剩余交易日不足窗口长度，该样本不计入该窗口。
- 未成交反事实：决策日或之前最近交易日为基准，次一交易日开盘买入，持有 5/20 个交易日收盘卖出。

### 8.2 样本限制

1. **样本期偏下跌。** 决策日集中在 2026-05 ~ 2026-11，成交组与未成交组在 +20 日都偏负；本诊断无法区分“保守”与“正确防御”。要验证“保守是否错过上涨”，需要一段趋势上行样本。
2. **成交价口径偏保守。** 回测按入场区上沿成交，真实限价单大概率在下沿或更好；因此本文的“入场价”偏高、“止损距离”偏宽。若按下沿成交重算，止损距离会更窄，零缓冲问题会更突出。
3. **样本量有限。** 54 笔成交、40 笔止损，分组后零距离 15 笔、窄 18 笔、宽 7 笔；宽止损组只有 7 笔，分组结论只能作为方向性证据，不能当作统计显著结论。
4. **未计入交易成本。** 本文收益均为价格收益，未扣佣金、印花税和滑点；74% 止损、1 天持仓的 churn 在真实成本下会更差。
5. **`entry_rule` 是推断字段。** `immediate` 对应 `conditional_open`，不是“市价立即买入”；文中已按执行模式而非字面含义解读。

## 9. 修复落地与前后对照

> 本节记录按第 7 节建议落地的**结构修复**及其效果。修复只动结构，不动入场触发价，也不为了让回测好看而放宽止损。
>
> **2026-11-19 更新：本节 9.1–9.4 描述的是当时的临时实现，其中“校验层改写点位”的部分已按外部依据核查结论回退。** 依据见 [交易计划生成端的结构校验：外部依据核查与改动裁定](selection-pipeline-trade-plan-guard-evidence-review.md)。最终形态是**只判定、只建议、不改写任何点位**的校验器，见 9.5；回测限价口径（B1）与 `entry_rule` 映射（B2）保持不变。9.1–9.4 仅作为历史实现与样本内对照记录保留。

### 9.1 改了什么

**生成端（提示词 + 校验层）**

- 新增 `src/agent/trade_plan_guard.py`，在最终报告落盘前校验每个 pricing 场景和持仓计划：
  1. 入场区间宽度为零或过窄时，**只抬高 `entry_zone_high`，保持 `entry_zone_low`（限价触发价）不变**；最小宽度为 `max(0.20 × ATR20, 0.5%)`，上限 3%。
  2. `stop_loss` 必须严格低于 `entry_zone_low`；等于或高于下沿时，按 ATR 距离重算，记录 `stop_loss_below_entry_zone`。
  3. 止损距离夹在 `[0.5 × ATR20, 2.5 × ATR20]`，再夹在 `[1%, 8%]` 绝对区间；前者让止损随波动调整，后者防止极端行情下止损过宽。
  4. `stop_loss` 高于整个入场区（关系倒置）时不强行修正，标记 `trade_plan_rejected` 并降级为 `wait`/`monitor`。
- 修正记录写入 `trade_plan_adjustments`，stage 级汇总写入 `trade_plan_guard`，便于审计。
- ATR20 只读本地历史缓存（`load_history_df(..., fallback_to_network=False)`），不新增下载；缺失 ATR 时仍按 1%~8% 绝对边界修复，并记录 `atr_unavailable`。
- `build_pricing_agent_prompt` 和 `build_portfolio_allocation_prompt` 增加同样的硬约束，尽量在模型输出阶段就避免非法结构。

**回测端（口径修正）**

- `_simulate_strict` 改为真实限价买单：`low <= entry_zone_low` 触发，成交价取 `min(entry_zone_low, 当日 open)`；跳空低开按更优的开盘价成交。
- `_build_trade_plan` 优先读取生成端写入的数值字段，`trade_plan_rejected` 的计划标记为解析失败并跳过。
- `_infer_entry_rule` 如实映射：`conditional_open → conditional`，`immediate_open → immediate`，`wait/plain_wait → unknown`。

### 9.2 结构修复覆盖了多少

对原 54 笔成交计划逐条重放：

| 指标 | 数量 |
| --- | ---: |
| 零宽入场区 | 17 |
| 止损等于或高于入场区下沿 | 16 |
| 触发至少一条修正 | 41 |
| 关系倒置被拒绝 | 0 |

也就是说，54 笔里有 41 笔的计划结构不合法；修复后全部得到数值上的修正，且没有出现“止损被抬到入场价之上”的反向错误。

### 9.3 同一批 54 笔的前后对照

口径说明：基线按原回测逻辑（进区间后按上沿成交、原止损）在**同一份日线**上重放；修复后按下沿限价成交 + ATR 止损重放。两者使用同一批 54 条计划，因此差异来自本次修复，而不是样本变化。

| 指标 | 基线（上沿成交 + 原止损） | 修复后（下沿限价 + ATR 止损） |
| --- | ---: | ---: |
| 成交笔数 | 54 | **45**（9 笔未触及下沿） |
| 止损距离 p25 / 中位 / p75 | 1.52% / **3.33%** / 5.45% | 2.55% / **3.07%** / 4.40% |
| 止损距离 ≥1 ATR 占比 | 30.6% | **19.0%** |
| 止损距离与 ATR20 相关系数 | **-0.20** | **+0.15** |
| 持仓天数中位 | **1** | **2** |
| 胜率 | **16.7%** | **13.3%** |
| 已实现收益中位 | **-2.55%** | **-2.95%** |
| 止损离场占比 | 74.1% | **80.0%** |

**怎么读这张表：**

1. **结构修复生效了。** 止损距离与 ATR20 的相关系数从 -0.20 转为 +0.15，说明止损开始随波动调整；止损距离的下四分位从 1.52% 抬到 2.55%，零缓冲/过窄止损被拉开。
2. **限价口径让 9 笔不再成交。** 这 9 笔原先是“价格进入区间但没跌到下沿”就按上沿成交；按真实限价单，它们本来就不会成交。成交率下降是口径变诚实的代价，不是策略变差。
3. **结果略变差，且没有变好。** 胜率 16.7% → 13.3%，收益中位 -2.55% → -2.95%，止损离场占比 74.1% → 80.0%。持仓中位从 1 天变 2 天，说明止损确实比原来宽了一点，但在这批下跌样本里，更宽并没有换来更高胜率。
4. **不能据此反推“应该把止损调窄”。** 这批样本在诊断阶段已经确认整体偏下跌：未成交组 +20 日中位 -11.01%，成交组从成交价持有 20 日中位 -9.07%。在下跌样本里，任何“拿得更久”的改动都会偏负；这不能证明结构修复方向错误，也不能证明原来的 1 天止损更好。

### 9.4 结论与边界

- 本次修复解决的是**机械结构缺陷**：零宽区间、止损贴下沿、止损与波动无关、极端止损无上限。四项都已在校验层拦住，并留下审计记录。
- **没有改动入场策略**：`entry_zone_low` 保持不变，挂多低仍由模型和原有提示词决定；本次没有收窄或放宽“等回踩”的幅度。
- **没有为了回测调参**：ATR 倍数和 1%~8% 边界来自仓库现有口径（`max_stop_distance_atr=2.5`、`zone_padding_atr=0.10`、显著波动 floor 1% / cap 8%），不是按本样本收益反推的。
- 修复后样本内结果略差，已如实记录。若后续要验证“入场端是否该放开”，应在趋势上行样本上单独做影子重放，不应把本次结构修复的结果当作放宽入场的依据。

### 9.5 最终形态（2026-11-19）

按 [依据说明文档](selection-pipeline-trade-plan-guard-evidence-review.md) 的结论回退后，生成端只保留**校验器**：

- 提示词第 10/11 条（pricing）与第 20/21 条（portfolio）已删除，恢复原样；点位由模型按原有提示词给出。
- `src/agent/trade_plan_guard.py` 不再提供任何写回函数，只返回 `status`（`ok` / `needs_review` / `invalid`）、`issues` 与 `suggestions`（`advisory_only=True`）。
- 零宽区间、止损距离与 ATR 脱钩只产生 `warning`；不再抬高 `entry_zone_high`，也不再夹取止损距离。
- 止损不低于可成交价（`entry_zone_low`）或高于整个入场区时判定 `invalid`，由调用方拒绝或回问模型，校验器不代填新价格；`invalid` 计划不降级 `action`、不清零仓位，原始计划原样保留。
- 判定与建议写入 stage 级 `trade_plan_validation`，只包含非 `ok` 条目，便于审计；`invalid` 条目标记 `blocked=true`，表示不得执行。
- 回测侧 B1（`low <= entry_zone_low` 触发、`min(entry_zone_low, open)` 成交）与 B2（`entry_rule` 如实映射）保持不变；9.3 的 54 笔对照仍成立，但其中“ATR 止损改写”带来的差异不再适用于当前实现。
