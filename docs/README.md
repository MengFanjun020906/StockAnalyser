# 文档目录

本目录按文档用途分层，`CHANGELOG.md` 保留在 `docs/` 根目录。

## 常用入口

- [完整指南](full-guide.md)：安装、配置、运行、WebUI、数据源和排障。
- [LLM 配置指南](LLM_CONFIG_GUIDE.md)：模型渠道、OpenAI-compatible 路由和常见问题。
- [FAQ](FAQ.md)：常见使用问题。
- [openInvest 原理实际接入点索引](integrations/openinvest-principles-integration-map.md)：说明 Regime、新闻、多席位、辩论、Judge sanity、telemetry 和复盘在后端链路中的真实落点。
- [更新日志](CHANGELOG.md)：版本变更记录。
- [English documentation index](i18n/INDEX_EN.md)：英文文档入口。

## 分类目录

- `architecture/`：系统架构、选股链路、协议和字段契约。
- `modules/`：已实现或长期维护的模块说明、开发指南和专题工具文档。
- `plans/`：方案、路线图、实施计划、调研和旧稿归档。
- `deployment/`：部署、迁移、桌面端打包和云端 WebUI 指南。
- `integrations/`：外部项目、Skill 或产品集成评估。
- `bot/`：机器人配置图文材料。
- `i18n/`：英文 / 繁中首页和英文索引。
